# PlayTimeTracker

PlayTimeTracker is a Minecraft mod for keeping track of player playtime and activity on a server.

## Commands

### Playtime

- `/playtime <Player>` - Shows the player's total playtime.
- `/laston <Player>` - Shows when the player was last online.
- `/playtimerop <Number>` - Shows the players with the most playtime.

### Activity

- `/actifity <Player> <Number>` - Shows the activity of a player.
- `/allactifity <Number>` - Shows the activity of all players.

### Inactive Players

- `/inactif kick <Player>` - Kicks a player marked as inactive.
- `/inactif restor <Player>` - Restores a player from the inactive list.
- `/inactif list` - Shows all players currently marked as inactive.
