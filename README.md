# PlayTimeTracker

PlayTimeTracker is a Minecraft mod for keeping track of player playtime and activity on a server.

## Commands

### Playtime

- `/playtime <Player>` - Shows the player's total playtime.
- `/lastonline <Player>` - Shows when the player was last online.
- `/playtimetop <Number>` - Shows the players with the most playtime. (in a given time)

### Activity

- `/activity <Player> <Number>` - Shows the activity of a player. (in a given time)
- `/allactivity <Number>` - Shows the activity of all players. (in a given time)

### Inactive Players

- `/inactive kick <Player>` - Kicks a player marked as inactive.
- `/inactive restore <Player>` - Restores a player from the inactive list.
- `/inactive list` - Shows all players currently marked as inactive.

### Setting File
- Auto kick Player After `x` Days (0 to turn off)
